# 👋 Hello, I'm Cristian Teijeiro Parga

**Software Engineer** based in Madrid. I build products end to end: React/Next.js front ends, Node and Python back ends, Postgres/Supabase data layers, and AI features that ship instead of sitting in a notebook.

Currently a **Software Engineer at [Fusuma Advisory](https://fusuma.io)**, working on an accounting platform for advisory firms.

---

### 🚀 What I'm building

#### 🎾 Smashly — padel racket SaaS
Price comparison and discovery across every Spanish padel retailer, with affiliate-feed syncing and automated catalog scraping.
*   **Stack:** Next.js, TypeScript, Supabase (Postgres + RLS), Python scraping, Tailwind, Shadcn, TanStack.

#### 🎓 Sénea — SaaS for private teachers
Scheduling, student records and AI-generated progress reports for tutors and primary-school teachers. Multi-tenant with Stripe billing, credit-based AI metering and Playwright E2E coverage.
*   **Stack:** Next.js, TypeScript, Supabase, Clerk, Stripe, Resend, Playwright.

#### 🤖 Jarvis — self-hosted AI assistant
Personal agent running 24/7 on a Linux VPS: calendar, finances, nutrition, training and project tracking, with Telegram as the interface and a local TTS/STT voice loop.
*   **Stack:** Python, Hermes Agent, MCP, n8n, Cloudflare Workers, Docker, systemd.

#### 🧾 Orial — personal finance automation
Bank sync and expense classification on top of Supabase, with an iOS companion app.
